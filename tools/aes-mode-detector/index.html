🔍 How the detective works

Modes we investigate

  • ECB — Electronic Codebook (no IV)
  • CBC — Cipher Block Chaining (needs IV)
  • CFB — Cipher Feedback (needs IV)
  • OFB — Output Feedback (needs IV)
  • CTR — Counter (needs IV)

Key sizes we try

  • AES-128 — 16 bytes
  • AES-192 — 24 bytes
  • AES-256 — 32 bytes

We attempt every combination and check whether the decrypted output looks like real, readable text. When it does, we've likely found the mode and key size. Case closed!
