How It Works

Supported AES Modes:

  • • ECB (Electronic Codebook) - No IV needed
  • • CBC (Cipher Block Chaining) - Requires IV
  • • CFB (Cipher Feedback) - Requires IV
  • • OFB (Output Feedback) - Requires IV
  • • CTR (Counter) - Requires IV

Key Sizes Tested:

  • • AES-128 (16 bytes)
  • • AES-192 (24 bytes)
  • • AES-256 (32 bytes)

The tool attempts decryption with each combination and checks if the result is readable text.
