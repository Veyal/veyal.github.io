# veyal.github.io

Personal site of **Andrew Salim** ([@Veyal](https://github.com/Veyal)) — friendly neighborhood hacker.

Playful, candy-colored portfolio plus a suite of free client-side tools:

- **Encryptor** — encrypt/decrypt text in the browser
- **Password Generator** — cryptographically random passwords
- **JSON Beautifier** — format & validate JSON
- **AES Mode Detector** — spot ECB vs CBC from ciphertext patterns
- **Bill Splitter** — AI-powered receipt OCR bill splitting

## Stack

Next.js 14 (App Router, static export) · Tailwind CSS · framer-motion · Geist fonts. No backend — everything runs client-side.

## Development

```bash
npm install
npm run dev
```

## Deploy

Static export deployed to GitHub Pages (`gh-pages` branch):

```bash
npm run deploy
```
